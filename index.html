AI 導入成果

從「AI 輔助人」到「人輔助 AI」：把團隊開發經驗封裝成 AI 可重複執行的標準流程，AI 負責撰寫與初審，人負責定規格與把關。從 GitHub Copilot Agent 到 Claude Code，6 人團隊全數納入日常開發。

成果：建立團隊標準 AI 工作流程

  • 2個團隊 Skill
    開發／審查
  • 4個專責 Agent
    撰寫、IDE 操作、審查、Commit
  • 4個流程階段
    開發 → Review → Commit → 知識沉澱
  • 6 / 6團隊成員
    全數採用

整套流程與規範和遊戲專案的程式碼放在一起管理：新成員下載專案並完成簡單設定後，即可使用和全團隊相同的開發流程；規範有更新時，成員只要更新專案就能取得最新版本，不需要再個別口頭傳達。

  • 一鍵 Code Review一個指令完成 Review → Commit，審查品質一致
  • 每日自動審查問題自動通知作者，不必等人工發現
  • 規格驅動開發（SDD, Spec-Driven Development）先定規格、經人確認後 AI 才動手，依驗收條件驗收
  • AI 操作遊戲編輯器透過 MCP 直接編輯 Cocos Creator 場景與 Prefab
  • 開發知識沉澱開發決策寫成文件，下次開發自動引用
  • 企劃參與開發企劃用 AI 在分支上開發，不影響主線
  • 單一資訊來源專案資訊集中在 README，新人看文件就能上手

實作細節（/ts-review、/cocos-develop、SubAgent 與 Context Engineering 設計）請見作品區「AI 工作流作品集」。
